# Contributing to AtlasGBA

Follow [AGENTS.md](AGENTS.md) and the [development guide](docs/atlas/DEVELOPMENT.md).
The owner prefers direct, tested commits to `master`. Do not open a pull request
unless separately requested. If one is requested, both its destination and base
repository must be `ArmenionCH2/pokeemerald-expansion`.

Report Atlas issues in [this fork](https://github.com/ArmenionCH2/pokeemerald-expansion/issues),
with the commit, reproduction steps, save compatibility, and evidence from tests
or an emulator. Do not send Atlas changes or reports upstream. Upstream engine
documentation is technical reference, not Atlas contribution policy.
